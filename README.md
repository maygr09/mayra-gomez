# Mayra Gómez — Personal Portfolio

My personal website built with Next.js.

The goal of this project is to showcase my software engineering, data, and product development projects while documenting my learning journey.

## Features

- Responsive design
- Light / Dark mode (si lo tienes)
- Project showcase
- Interactive UI
- Library-inspired visual identity
- Blog (coming soon)
- Lab section for ongoing experiments

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
